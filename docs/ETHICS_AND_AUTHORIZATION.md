# Ethics and authorization

Use NullTrace AI only against systems you own, systems for which you have written permission, or intentionally vulnerable training labs.

Before any future remote assessment, define the exact host/application scope, permitted test categories, test window, request limits, data-handling requirements and emergency contact.

Stop immediately if testing causes unexpected impact. Do not access, retain or disclose real users' data. Use synthetic data for demonstrations. The current release only exercises a local mock target.
