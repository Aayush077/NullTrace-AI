# Roadmap

## 0.1 — Local foundation (included)
- CLI and local mock target
- Baseline, prompt-boundary and tool-permission checks
- Structured findings and JSON/Markdown reports
- Unit tests and documentation

## 0.2 — Hardened core
- Configuration schema and target scope model
- Evidence redaction and report schema versioning
- Additional local vulnerable-agent labs

## 0.3 — Optional integrations
- Opt-in HTTP adapter with strict allowlist, auth, timeout and request budget
- Provider adapters for controlled test environments
- Instrumented tool-call traces

## 0.4 — Research and dashboard
- Reproducible benchmark suite
- Cross-model evaluation
- Web dashboard using the same core services
